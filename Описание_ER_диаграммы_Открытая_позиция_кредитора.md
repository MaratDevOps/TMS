# Описание ER-диаграммы открытой позиции кредитора

ER-диаграмма открытой позиции кредитора FI-AP реализована условно. Для сервиса
казначейства система FI-AP не является частью внутренней модели данных и не представляет
самостоятельного предметного интереса.

FI-AP показана как пример внешней системы — источника заявок на оплату. Сервис казначейства
получает от неё данные по интеграционному контракту и создаёт на их основе заявку на оплату
в TRM.

Диаграмма нужна для понимания состава исходных данных и их идентификации при интеграции.
Она не описывает физическую модель SAP FI-AP и не ограничивает возможность получения
заявок от других внешних систем-источников.

Контракт интеграции определяет минимально необходимый набор данных, который система-источник
должна передать TRM; внутренняя структура и технологии источника для TRM несущественны.
