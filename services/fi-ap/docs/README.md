# Документация микросервиса FI-AP

FI-AP в рамках проекта — вспомогательный сервис для генерации платёжных потребностей.
Он не является полноценной реализацией SAP FI-AP и не моделирует бухгалтерский учёт.

## Назначение

Сервис создаёт множество тестовых открытых позиций кредиторов в параллельных потоках,
формирует по ним события `payment.demand` и отправляет события в Kafka. Он используется
для проверки интеграции, конкурентной обработки и поведения системы под нагрузкой.

## Минимальный функционал

1. Генерация открытых позиций кредиторов с обязательными реквизитами, необходимыми
   для формирования `payment.demand`.
2. Настройка количества создаваемых позиций и числа параллельных потоков.
3. Генерация уникальных `eventId`, `sourceLineItemId`, `lineItemID` и `documentKey`.
4. Формирование Kafka-события в соответствии с контрактом
   `Контракт_события_FI_AP_payment.demand.md`.
5. Публикация событий в топик `payment.demand` с `sourceLineItemId` в качестве Kafka key.
6. Повторная публикация одного события с прежним `eventId` для проверки дедупликации.
7. Публикация изменённой позиции с новым `eventId` и прежним `sourceLineItemId`
   для проверки обновления заявки в TRM.
8. Сбор результатов публикации: успешные и ошибочные отправки, длительность,
   пропускная способность и распределение событий по Kafka partitions.
9. Журналирование `eventId`, `sourceLineItemId`, Kafka partition, offset и ошибки
   публикации для последующего анализа.
10. Корректное завершение генерации с ожиданием отправки всех поставленных в очередь
    событий.

## Настраиваемые параметры

- адреса Kafka brokers;
- имя топика;
- количество событий;
- количество параллельных потоков;
- скорость или задержка генерации;
- доля повторных и изменённых событий;
- начальные значения генератора случайных данных.

## Вне области реализации

- полноценная модель SAP FI-AP;
- бухгалтерские проводки и расчёт задолженности;
- пользовательский интерфейс;
- управление корпоративными справочниками;
- бизнес-процессы согласования и оплаты;
- обработка заявок на стороне TRM.
